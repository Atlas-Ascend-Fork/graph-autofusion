# 性能劣化问题分析

遇到开启 SK 后性能劣化或收益不达预期的问题，转交 [SuperKernel 性能分析 skill](https://gitcode.com/cann/graph-autofusion/tree/master/.claude/skills/superkernel-fusion-performance-analysis)，按其入口说明开展分析。

准备未开启 SK 的 profiling、开启 SK 的 profiling，以及包含 SK profiling 的 `sk_meta`；其他材料按该 skill 的要求补充。

若现场已安装该 skill，读取其 `SKILL.md` 后使用；未安装或无法访问时，向用户提供上述入口，说明需要获取该 skill 后继续，不自行假定其具体定位步骤。
