# V1 ATT model archive

The [A3 MTE2 Load collection material](mte2/load/README_en.md) and [A3 MTE3 Store design and coverage index](mte3/store/README_en.md) follow the A3-to-V1 directory mapping. Their historical v35 parameter snapshots do not represent current V1 parameters or establish calibration or measured validation against V1. The Load archive also documents the V1 implementation parameters.

The V1 implementation is in [api_perf_register/v1](../../gen_model_info/api_perf_register/v1). The V1 parameter table inherits the default empty registration key; v35 uses `PerfParamTableV2` and key `V2`. These keys are not platform directory names.
