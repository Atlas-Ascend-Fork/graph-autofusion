# V1 ATT model archive

[A3 MTE2 Load collection material](mte2/load/README_en.md) is archived here with experimental designs, collection inventories, and the original parameter snapshot. The snapshot cites the v35 implementation and does not represent current V1 parameters; no validated V1 model fit or measured results are archived yet. The implementation is in [api_perf_register/v1](../../gen_model_info/api_perf_register/v1). The V1 parameter table inherits the default empty registration key; v35 uses `PerfParamTableV2` and key `V2`. These keys are not platform directory names.
