# FP32 窄连续源长轴 NDDMA 校准

[用例](../../../cases-narrow-source.csv) · [逐点数据](samples.csv) · [采集协议](manifest.json)

产品按物理 GM 连续宽度 M≤8 元素、转置轴 N=512–16384、GM pitch=30–512 元素、UB packed 的 FP32 描述符应用本式。
静态单位轴折叠为物理 1D 时沿用同一计量，低核分支仍按原选择。
表达式为 startup + N × (position_cost + contention_cost × max(C−32,0)/24)。
这是启动、搬运及核间竞争的原有结构，搬运量使用 strided position 数，避免用 UB payload 隐藏 GM 窄读。

只有五个独立 train 点参与最小化最大相对误差拟合，训练不含实际生产 M=1/3。
已知候选及后续长轴验证在系数冻结后比较，S03 的原脚本角色不参与拟合。
域外对照的 prediction 留空，避免将拟合式外推当作产品行为。

| --- | ---: | ---: |
| domain_control | 16 | — |

采集先验证所有输出与 UB 保护区，profiling 仅取 MTE2 API 调用次数斜率，
各调用次数的原始 medians、线性误差及启动项另存外部源索引。
单 API 拟合与最终模板排序分别验收，关闭 PGO 的默认结果如下。
49 GiB 为该实验长跨度、跨调用不同地址的输入池，需设备空闲并核对剩余 HBM。
工具在固定输入池及输出、校验区一起满足 HBM 预算时才执行。

## 默认选择验证

原默认 0120 的实际描述符为 `[3,4096]`、GM stride `[1,512]`、UB stride `[4096,1]`；
0134 为 `[1,12032]`、GM stride `[1,512]`、UB stride `[12032,1]`；0166 为 `[1,2048]`、GM stride `[1,30]`。
沿最终 kernel 的 dispatch 和 API 参数还原，不能用未被调用引用的其他 tile 字段推断长轴。
