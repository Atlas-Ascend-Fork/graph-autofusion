# MTE3 Performance Models

Archive v35 write-path models, including the historical A5 `StoreApi` (UB to GM) calibration and the small contiguous Store extension.

```text
mte3/
├── README.md
├── README_en.md
└── store/
    ├── README.md
    ├── design.md / cases.csv              # Small contiguous Store extension
    ├── design-legacy.md / cases-legacy.csv # Original A5 calibration archive
    ├── parameters.json                   # Original parameter snapshot
    └── results/                          # Validation results
```

Entry point: [A5 Store (UB2GM) model archive](store/README_en.md). The A3 archive is under [V1 Store](../../v1/mte3/store/README_en.md).

See the [archive conventions](../../README_en.md) for the model file structure.
